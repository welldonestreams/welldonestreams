1. Get Access (you only do this once)

Fill in your name and Plex email address. I will add you to the server within 24 hours.

While you wait for the invite email, head to step 2 ↓ to get set up.

2. Get the App & Set Up Your TV

TV sign-in: You won't type your password on a TV. The Plex app shows a 4-character code. On your phone or computer, go to plex.tv/link, sign in, and enter the code. Some apps also show a QR code to scan.
Roku

Home → Streaming Channels → Search → "Plex" → Add Channel. Launch → Sign In → enter the code at plex.tv/link.

Fire TV

Find → Search → "Plex" → Download. Launch → Sign In → code at plex.tv/link.

Android TV / Google TV

Google Play Store → search "Plex" → Install. Launch → scan the QR code or enter the code at plex.tv/link.

Apple TV

App Store → search "Plex" → Get. Launch → Sign In → code at plex.tv/link.

Samsung

Samsung Apps → search "Plex" → Install. Availability varies by model year; very old sets may not have a current app — use a cheap streaming stick if so.

LG (webOS)

LG Content Store → search "Plex" → Install. Same model-year caveat as Samsung.

Gaming Consoles

Plex is available on Xbox (One, Series S/X) and PlayStation (PS4, PS5). Open the console's store — Microsoft Store or PlayStation Store → search "Plex" → Install/Download. Launch → Sign In → enter the code at plex.tv/link.

Any web browser

Go to app.plex.tv and sign in — no install and no code needed. The best fallback if a device app won't cooperate.
