1. Get Access (you only do this once)

Fill in your name and Plex email address. I will add you to the server within 24 hours.

While you wait for the invite email, head to step 2 ↓ to get set up.

2. Get the App & Set Up Your TV

TV sign-in: The Plex app shows a 4-character code. On your phone or computer, open plex.tv/link, sign in, and enter it.
Roku

Home → Streaming Channels → Search → Plex → Add Channel. Launch and enter the code at plex.tv/link.

Fire TV

Find → Search → Plex → Download. Launch and enter the code at plex.tv/link.

Android TV / Google TV

Install Plex from Google Play, then scan the QR code or enter the link code.

Apple TV

Install Plex from the App Store, launch it, and enter the displayed link code.

Samsung / LG

Install Plex from the TV's app store. Older sets may need a streaming stick.

Xbox / PlayStation

Install Plex from the console store, launch it, and enter the displayed link code.

Web browser

Open app.plex.tv and sign in.
